## 已核实事实

- 2026-11-06（周五）晚约 8 时 10 分，墨尔本市中心 Frederick Way（维多利亚女王市场附近）：47 岁中国籍熊猫外卖骑手冯建明与另一名 34 岁骑手发现一名陌生男子在摆弄他们的车，上前交涉，发生冲突；冯建明胸口被刺，当场身亡；34 岁骑手也被刺伤送医，无生命危险（周六已出院）。
- 目击者称：冯建明进餐厅取餐时，外面一名流浪汉故意推倒其电动自行车，冯建明出来理论，对方突然拔刀刺向其胸口；中刀后冯建明仍走回餐厅想取餐，似乎没意识到自己伤得有多重。
- 2026-11-07 上午，维州警方逮捕一名 51 岁男子（来自 Footscray），目前仍被羁押，警方表示不再寻找其他涉案人员；警方展开凶杀调查。
- 冯建明：47 岁，陕西人，2017 年来澳，9 年没回过国；妻子和两个 20 多岁的孩子在国内；家中主要经济支柱，还供养中风后住养老院的父亲；同事称他生活节俭，挣的钱几乎都寄回国内；餐厅店主称他每次取餐都会帮忙重新系紧袋子。
- 2026-11-07，中国驻墨尔本总领馆发布通报：6 日晚一名中国公民在墨尔本市区遇害，嫌疑人已被缉拿归案；总领馆启动领事保护应急机制，要求警方全力彻查、依法公正处理、严惩凶手；已联系家属，协助善后。
- 熊猫外卖回应：7 日上午发声明深感悲痛，成立专项小组核实身份；7 日晚再次回应：承担家属赴澳交通费、丧葬费及必要善后支出，另给一笔抚恤金；下周在墨尔本组织骑手面对面沟通会，听取配送安全、平台政策意见；已向保险公司报告，协助家属申请理赔；为家属联系独立律师并承担费用；平台表示因餐品盗抢、或骑手为保障自身安全无法完成配送，不会要求骑手承担餐品损失或处罚。
- 争议：事发后“熊猫外卖骑手需自行赔付配送途中被偷、被抢的外卖餐品”话题引发讨论；冯建明的朋友涂先生向红星新闻表示，平台罚款严格，餐被偷或撒了要全额赔付，冯建明的外卖被流浪汉抢了，他要拿回来，间接导致后面的事情；出事街区此前发生过抢外卖的情况。
- 悼念：2026-11-07 下午 5 时许，数百名华人在维多利亚州立图书馆门前集会悼念，草坪摆满鲜花和白色蜡烛，有人手写书信；遇害地点也有人送花；现场标语包括“RIP NO DELIVERY IS WORTH A HUMAN LIFE”（没有一单外卖值得一条人命）、“WE NEED A SAFER MELBOURNE”（我们需要一个更安全的墨尔本）、“他送餐为了支付孩子学费，却再也没有回家”；有人要求对熊猫外卖的政策进行独立审查；墨尔本唐人街商业协会发起 GoFundMe，已筹得 7000 多美元，帮助家属赴澳及丧葬。
- 熊猫外卖由中国留学生刘科路 2017 年在英国诺丁汉创立，主要服务海外华人。

## 未核实 / 未采用

- 嫌疑人年龄 61 岁：仅一家转载写 61 岁，多家写 51 岁，采用 51 岁。

- “胸部被刺数刀”：一家转载称“胸部被刺数刀”，AAP/7NEWS 只写胸部中刀，正文只写“胸口被刺”，不写刀数。
