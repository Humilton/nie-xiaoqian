## 已核实事实

- 2003年5月1日（星期四），约旦安曼阿利亚王后国际机场北出发厅，行李安检处发生爆炸，1人死亡、3人受伤。
- 死者是约旦机场安保警士阿里·萨尔汉（Sergeant Ali Sarhan）。
- 记者名叫五味宏基（Hiroki Gomi），36岁，日本《每日新闻》（Mainichi Shimbun）摄影记者。
- 他在巴格达从一名伊拉克人手里买下这件爆炸物，打算带回日本当作战地纪念品；被审讯时他说，自己不知道这件东西会爆炸。
- 2003年4月28日，他从伊拉克经卡拉马口岸进入约旦，准备搭乘埃及航空飞往开罗的航班。
- 2003年5月，约旦国家安全法院判处他监禁18个月。
- 2003年6月11日，约旦内阁通过决议，对他实行特别赦免；2003年6月16日，阿卜杜拉二世国王颁布王令，赦免了他。
