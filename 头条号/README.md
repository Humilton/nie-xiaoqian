# 头条号

头条号浠水文艺的扎心情绪文和反转故事文草稿，每篇一个文件夹，文件夹名是日期加中文故事名。

每篇文件夹里，正文.md 只写可以直接发头条号的内容，不含标题选项、来源、参考文献和图片插入标注。标题、参考文献、核实记录、图片说明和图片插入位置等非故事性内容，都写在本篇的 README.md 里。

图片均为 AI 生成的仙侠清新风格插画，不是原图，不是真实照片，不是现场照片。

- 20261106_宁波医生夫妻菜市场救人：主标题是菜市场里倒下一位老人，冲上去的两个买菜人，身份让全城都愣住了，正文 1544 字，3 张图，状态待审核，未发头条

## 怎么发

- 等用户审核通过后，一篇一篇发头条号，一次只发一篇
- 标题填各篇 README 里的主标题或备选标题，正文贴各篇正文.md 全文，图片按各篇 README 里的插入位置插在段落之间
- 发头条时勾选 AI 引用声明，首发不勾
- 发完后以作品管理为准核对，状态记回各篇 README
