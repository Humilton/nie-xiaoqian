# 头条号

头条号浠水文艺的扎心情绪文和反转故事文草稿，每篇一个文件夹，文件夹名是日期加中文故事名。

每篇文件夹里，正文.md 只写可以直接发头条号的内容，不含标题选项、来源、参考文献和图片插入标注。标题、参考文献、核实记录、图片说明和图片插入位置等非故事性内容，都写在本篇的 README.md 里。

图片：有来源文章原图的用原图（版权状态未核实、先行配用），无原图的用 AI 生成的仙侠清新风格插画，不是真实照片，不是现场照片。

## 怎么发

- 等用户审核通过后，一篇一篇发头条号，一次只发一篇
- 标题填各篇 README 里的主标题或备选标题，正文贴各篇正文.md 全文，图片已用 ![说明](文件名) 形式插在各篇正文的段落之间，发头条时按正文里的图片顺序上传
- 发头条时勾选 AI 引用声明，首发不勾
- 发完后以作品管理为准核对，状态记回各篇 README
