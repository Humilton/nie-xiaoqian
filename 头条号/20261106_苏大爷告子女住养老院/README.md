## 已核实事实

- 苏大爷 90 多岁，重庆人，常年需要专人看护
- 近十年来，他一直跟着长子生活，长子一家的照料越来越吃力
- 苏大爷提出想搬到城区的养老院生活，每月费用 3700 元，由 6 个子女平摊
- 子女不同意，普遍认为在家中赡养即可，养老院费用太高
- 子女愿意出钱养老，报道原文以此设问：明明子女愿意出钱养老，老人为何还要一纸诉状将亲生子女告上法庭
- 讨论无果，苏大爷将 6 个子女告上法院
- 他的要求：每人每月支付 700 元赡养费，送他去养老院居住，同时要求子女定期探望
