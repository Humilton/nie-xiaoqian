## 写作原则

- 只写已公开披露的事实：吴凯其人、2024年8月对刘仁的公开指控、2024年10月“少校”悬赏与赵冰接单、2024年11月10日至13日的劫持、转移、弃尸与发现尸体、惠州中院一审判决、广东高院二审维持原判、赔偿与谅解书、刘仁2026年6月被带回的通报。
- 指控与传言一律标明出处，不写成定论：对刘仁的罪名是吴凯的公开指控，刘仁方面予以否认；死后“被捕”“涉人口贩卖、敲诈、逃税”等说法是传言与编造，文中按友人（化名）的说法转述，不作事实认定。
- 未证实者不作定论：公安部关于刘仁被带回的通报，未将刘仁与吴凯遇害相联，也未将刘仁与“少校”相联；吴凯亲属称据其所知“少校”尚在境外，未被抓获。文中如实保留这两点，不推断“少校”即刘仁。
- 没有编造对话、没有编造未见报道的殴打细节、没有编造人物关系：张扬飞、老安均为化名；吴正杰为吴凯之子（据新京报报道中“到其家寻其父”的表述）。
