## 人物表（先写人物表，再按人物表生成图片）

- 罗子浮：邠州青年书生；初为破旧灰袍，后为绿袍；四图中面部特征一致。
- 翩翩（薛姑子）：山洞仙女；长发，穿飘逸浅绿长袍；四图中均为同一装束。
- 花城娘子：来访的少妇仙人；穿粉红长袍，戴花钗。
- 罗大业：罗子浮的叔父；仅文字出场，本篇未单独配图。
- 保儿：罗子浮与翩翩之子，少年；穿蓝袍。
- 新妇：花城娘子之女；穿粉红衣裙。
