# 聊斋志异-清-蒲松龄

清代蒲松龄《聊斋志异》白话翻译全书计划，底本锁定 12 卷 491 篇（张友鹤会校会注会评本），494 篇版多出的篇目另列附录，不混入主序号。

## 结构

- 卷名和篇名用中文，按卷分文件夹：卷一至卷十二
- 每篇文件夹命名：全局序号 + 篇名，例如卷一/001-考城隍/
- 每篇文件夹内分开两篇：001-篇名-原文.md（公有领域原文，不抄现代整理本校注和现代译文），001-篇名-白话.md（Muse 翻译，开头标明 Muse 翻译和底本）
- 图片：images/01.webp 至 05.webp，每篇 2 到 5 张，仙侠风格、清新一些，服饰不统一，按每篇题材自定，同篇内同人同脸同服装，主要人物都要出现
- 发布版：白话在前、原文附在后，只在头条发布时拼，GitHub 上原文和白话分开

## 规则

- 忠实原文，不加人物、不改结局，段落换行跟原文走、段内句子连续、不加小标题
- 有“异史氏曰”的按原文段落保留，不删
- 每 10 篇一包：取原文、翻译、配图、自查、推 GitHub、等用户审包、只改用户点名的篇
- 每天稳妥档 3 篇，试跑 10 篇后以实测为准，超限额自动降到每天 1 到 2 篇
- 头条：每包 GitHub 审完后，再一篇篇发，不等全书推完；头条首发先不勾，除非用户单篇明确说勾；发表渠道逐项单独批
- 翻译尚未开始，本目录为计划和目录骨架，试跑前先做第 0 段目录和模板
