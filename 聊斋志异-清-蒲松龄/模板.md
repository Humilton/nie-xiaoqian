# 聊斋志异翻译模板（第0段，试跑前冻结）

## 每篇文件夹

卷X/NNN-篇名/
- NNN-篇名-原文.md：公有领域原文，注明底本和来源页，不抄现代整理本校注、不抄现代译文
- NNN-篇名-白话.md：Muse 翻译，开头约 100 字，写明出自《聊斋志异》卷X、Muse 翻译、只把文言换成今天的话、原意不改、情节不增不减、不加人物、不改结局
- images/01.webp 至 05.webp：2 到 5 张，按段落插在白话正文段落之间，不插在段落中间
- README.md：本篇人物表、图片清单、校验结果、状态

## 白话正文校验清单

- 段落换行跟原文走，原文换行处换行，原文不换行处不换行，段内句子连续，不按句分行
- 不加小标题，不加现代评注进正文，有“异史氏曰”的按原文段落保留在最后
- 不加人物、不改结局、不改关键情节顺序，难懂的词用今天的话讲清楚，不编新情节
- 开头约 100 字要数出来，写进本篇 README
- 敏感、情色、暴力描写：不删情节改结局，语言收着写，单独标“待用户审”

## 图片模板（仙侠、清新、服饰不统一）

- 风格基调：仙侠、清新、明亮干净，不阴森、不破旧、不血腥夸张
- 服饰不统一：按每篇人物身份和时代自定，不全书套同一套服装
- 同篇一致：同一篇里同一个人同脸、同发型、同服装、同配饰，不同图片之间不能换脸换衣
- 人物表先行：每篇先写人物表（姓名、年龄感、服装、发型、标志物），再按人物表生成图片，生成后逐张看脸和服装
- 数量：2 到 5 张，短篇 2 张、长篇按段落取 3 到 5 张，不为凑数加无关画面
- 失败处理：生成失败记入清单，不盲目重跑，等用户定换提示词还是换画面

## 图片提示词骨架（每篇填空）

仙侠、清新、明亮，[人物：姓名、服装、发型、标志物]，[场景：地点、时间、氛围]，[动作：本段情节，不借上段、不提前下段]，不加文字，不加水印

## 推送和审包

- 每 10 篇一包，推 GitHub 后等用户审包，只改用户点名的篇
- 每天稳妥档 3 篇，试跑 10 篇后以实测为准，超限额降到每天 1 到 2 篇
- 头条：每包 GitHub 审完后再一篇篇发，发布版 = 白话在前、原文附在后，首发先不勾，除非用户单篇明确说勾
- 状态只有四种：草稿、已推 GitHub、用户已审、已发头条，不写“已上线”这种未核实的状态
