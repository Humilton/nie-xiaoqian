## 人物表

- 张某：山东人，流寓河南的父亲。
- 前妻：张讷之母，早卒。
- 牛氏：继室，张诚之母，性情凶悍，虐待张讷。
- 张讷：长子（按齿序为老二），二十二岁，樵夫，后寻弟至金陵。
- 张诚：次子，十六岁，塾生，性孝友，助兄砍柴，后被虎叼走、为张别驾所救。
- 张别驾：四十一岁，长兄，原为张诚的养父，后认出为同母异父的长兄。
- 太夫人：张别驾之母，曾嫁张父三年，后流离北去。
- 张炳之：祖父，仅在太夫人问句中出现。
- 黑固山：太夫人自述中提及的人名，原文保留。
- 巫：村中走无常者，引张讷入冥司。
- 皂衫人：冥司检牒者。
- 菩萨：云中伟人，以杨柳枝洒甘露。
