## 人物表（本篇内一致）

- 宁采臣（原文作“甯采臣”）：青年书生，浅蓝素色长衫，束发，温润正直。
- 聂小倩：十七八岁少女，素白衣裙，乌发简单发髻，素净发簪，清丽；成婚时改穿红底金纹喜服。
- 燕赤霞：中年剑客，深灰粗布长衫，短须，身边带旧木匣，剑藏匣中，另赠破革囊。
- 宁母：老年妇人，深色端庄衣裙，银发髻。
- 老媪／姥姥：老年妇人，深色旧衣，月下与妇人低语；本篇图片未单独为其立像。

- 姓名字形：维基文库原文作“甯采臣”，通行现代版本多作“宁采臣”；原文保留“甯”，译文用“宁”，指同一人。
