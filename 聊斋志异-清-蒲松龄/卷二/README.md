# 卷二

《聊斋志异》卷二，共 40 篇（043-082），原文与译文分开存放，每篇一个文件夹。

- 原文：维基文库《聊斋志异/第02卷》公有领域原文，转简体字，内容和段落不变，未抄现代整理本校注、未抄现代译文。
- 译文：Muse 的古文改白话讲述，逐段忠实改写，不加人物、不改结局，正文直接从故事第一句开始，不写来源、不写“白话”一词，介绍只写在各篇 README 里。
- 图片：每篇 2-5 张，仙侠风格、清新明亮，同篇同人同脸同服装，图只插在段落之间。
