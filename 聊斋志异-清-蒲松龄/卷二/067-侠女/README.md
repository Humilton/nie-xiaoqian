## 人物表（先写人物表，再按人物表生成图片）

- 顾生：二十五岁金陵书生，家贫，以书画为生，穿素色深青布袍，黑发发髻。
- 侠女（对户女郎）：十八九岁少女，秀美端庄，神情凛然，穿素色淡青衣裙，黑发发髻；腰间革囊藏晶莹匕首。
- 顾母：年老老妇，灰发发髻，穿素色蓝灰衣裙。
- 少年（娈童，白狐）：容貌俊美的少年，来求画，穿素色浅灰长袍；原形为白狐。
- 老妪（侠女之母）：聋老婆婆，灰发，穿素色布衣。
