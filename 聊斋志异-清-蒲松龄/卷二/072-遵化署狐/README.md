## 人物表

- 邱公：诸城人，任遵化道，刚烈；两幅图中均为黑须中年官员，深蓝官袍配补子、黑官帽，面容与服饰保持一致。
- 狐群：聚族居住在官署最后一座楼里，时常出来祸害人。
- 逃狐：炮击中化作一缕白气冲空逃走；两年后化作老叟到朝廷喊冤、指认藏金地点，随后不知去向。
- 干仆：邱公派遣往京城谋求升迁、暂将银子窖藏于班役家中的仆人。
- 班役：银子暂藏之家的主人一方（查验现场的班役之家）。
