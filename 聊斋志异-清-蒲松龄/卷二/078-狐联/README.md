# 078 狐联

## 说明

本篇由 Muse 翻译，底本为维基文库《聊斋志异》第02卷所载公有领域原文，转写为简体中文，仅做字形转换，内容与标点未改动；另以多个简体与繁体通行本交叉核对，文字一致。

原文本为单一段落；译文按场景自然断为 3 段（夜访拒狐、言语相戏、对联而去），内容顺序与原句一一对应，未增人物、未改结局、非梗概。图片仅插在译文段落之间。

## 人物表

- 焦生：章丘石虹先生的叔弟，在园中读书，蓄须如戟，平生不敢二色，正色拒狐。
- 年长女子：约十七八岁，狐，着浅粉色汉服，簪简单发簪，出联相戏。
- 年幼女子：约十四五岁，狐，着浅绿色汉服，随年长女子同来。
- 石虹先生：焦生的兄长，仅在首句提及，未出场。

## 图片

- images/02.webp：插在译文第 2 段之后。同一书房、同一人物与服饰，年长女子笑着出联，焦生凝思对不出。

## 版本异文说明（未采纳，仅备查）

- 石虹：个别版本作“石红”，从多数本与注家“姓焦，名毓瑞，别字石虹”作石虹。
- 戊戌：个别繁体本作“戊戍”，从简体通行本作戊戌；下联“己巳”各本一致。
- 床第：个别本作“床笫”，从简体通行本作床第。
- “下元鬼神”：注家疑“元”为“无”字之误，原文未改，译文按字面译为“下界的鬼神”。
- 结尾：个别繁体本在“一笑而去”后另有“长山李司寇言之”一句，多数简体本无此句，本篇未收。
