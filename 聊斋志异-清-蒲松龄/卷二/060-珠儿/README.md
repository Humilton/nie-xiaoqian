## 人物表（同篇形象一致）

- 李化：五十余岁的中年男子，深青色长袍，黑色发髻，短须
- 珠儿／詹氏儿：七八岁男孩，浅蓝布衣，圆脸，小发髻配浅蓝发带；复活后仍用同一形象
- 眇僧：独眼僧人，灰色僧袍，持钵
- 小惠：十四岁少女，冥中为贵妇；借体相见时着紫帔、戴幞头
- 李母：老年妇人，素色衣裙，灰白发髻
- 东邻赵氏女：少年女子，紫色衣袍，借体时作小惠言行
