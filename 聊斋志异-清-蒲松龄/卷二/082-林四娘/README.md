# 082 林四娘

Muse 翻译：本篇为《聊斋志异》卷二第 082 篇〈林四娘〉的忠实白话讲述，原文与白话段落一一对应，不增人物、不改结局；首夜亲昵处仅作克制叙述，未作渲染。

## 底本

- 底本：维基文库《聊斋志异》第 02 卷所载公有领域原文，转写为简体中文，内容与段落划分不变，仅作简繁转换；后半部分经古诗文网同篇原文交叉核对补全（维基文库卷页分页读取时曾遇限流，遂以古诗文网为核对来源，未凭空补写）。

- 本篇原文无异史氏曰，结尾即林四娘所留之诗；后世选本附载的“诗中重复脱节，疑有错误”一句为后人按语，未计入正文。

## 人物表

- 林四娘：衡王府宫人，遭难而死十七年后与陈公相遇；二十岁，善音律、能品诗，夜诵《准提》《金刚》诸经咒，三年后因生前无罪、死犹不忘经咒，蒙冥王许其投生王家而长别。
- 陈公宝钥：青州道官员，福建人；夜独坐时遇林四娘，三年相伴，临别受诗并珍藏。
- 陈公夫人：窥见林四娘容貌，疑其为鬼狐、惧为厌蛊，劝陈公绝之。
- 冥王：仅于告别时由林四娘转述，许其投生王家。
