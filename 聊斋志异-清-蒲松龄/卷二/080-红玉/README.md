## 人物表

- 冯相如：广平秀才，冯翁之子，卫氏之夫，后为红玉之夫。
- 冯翁：冯相如之父，年近六旬，性情方正耿直，家境贫寒，后被宋氏家人殴打，愤懑呕血而死。
- 红玉：初称东邻女，实为狐；赠银助冯相如娶卫氏，大难后携福儿归来，操持家业，与冯相如成婚。
- 卫氏：吴村卫家之女，年十八，勤俭顺德，与冯相如生子福儿，后被宋氏抢去，不屈而死。
- 福儿：冯相如与卫氏之子，幼时被官役抛弃于南山一带，后由红玉抱养于秦地，带回团聚。
- 宋氏：本邑缙绅，前任御史，因行贿被罢官，居乡作威，抢夺卫氏，致冯家破亡，后其父子三人及一媳一婢被杀。
- 虬髯丈夫：前来吊唁的义士，激冯相如报仇，并表示愿代冯相如行事，不留姓名。
- 邑令：初将冯相如收狱、革去功名，后见床头短刀而气馁，代为申辩，释放冯相如。
