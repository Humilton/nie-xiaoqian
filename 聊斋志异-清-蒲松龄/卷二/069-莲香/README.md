## 人物表

- 桑生（桑晓，字子明）：沂州人，少孤，在红花埠馆舍读书，性情沉静。
- 莲香：狐女，自称西家妓女，容貌倾国，性情爽直，善医，能辨鬼症，先后以药救桑生，产子后病故化狐，十年后转生为韦姓少女。
- 李氏：李通判之女，早夭葬于墙外，鬼魂，因阴气盛致桑生病重；后经莲香救治，借张家燕儿之躯还魂。
- 燕儿：富室张姓之女，年十五而死，李氏魂魄附体还魂，复原为李氏容貌，后与桑生成婚，抚养狐儿。
- 东邻生：桑生的邻舍书生，最初以假妓戏弄桑生，后又往窥燕儿之事。
- 狐儿：莲香与桑生之子，莲香死后由燕儿抚如己出。
- 韦姓少女：十四岁，徐城卖浆者之女，莲香十年后转生之身，经燕儿呼唤而记起前生。
- 异史氏：篇末评者。
