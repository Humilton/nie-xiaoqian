# 077 口技

## 介绍

这是聊斋志异卷二第 077 篇《口技》的 Muse 翻译。故事讲村里来了一位卖药女子，她自己开不出方子，却在夜里的小屋中以一人之口摹拟众姑、婢女、小儿与猫的声音，向病人“问神”开方；众人以为真神，试方却并不见效，原来这只是借口技售药的把戏，末尾又附一则京城少年以指捺颊、不用乐器而声如弦索的口技见闻。翻译按原文段落逐段对应讲述，不增人物，不改结局，不作梗概。

## 人物表

- 卖药女子：二十四五岁，携药囊，售其医；夜里闭置斗室，以口技摹拟众声问病开方。插图中统一为：二十四五岁的年轻女子，黑色长发简单发髻，浅青色汉服，腰间系小药囊。
- 九姑：声音清以越；随从婢女腊梅。
- 六姑：声音缓以苍；随从婢女春梅，春梅抱小郎子同来。
- 四姑：声音娇以婉；来得最迟，称路远且积水。
- 三婢、小郎子、猫儿：告别与嬉闹声中的声音角色；猫儿为小郎子远迢迢抱来。
- 王心逸：末段引述者，言京城少年以一指捺颊发声如弦索。
