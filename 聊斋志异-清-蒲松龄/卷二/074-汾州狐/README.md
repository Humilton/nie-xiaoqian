# 074 汾州狐

## 介绍

本篇为 Muse 翻译的《聊斋志异》卷二第 074 篇〈汾州狐〉。底本为维基文库公有领域原文，转写为简体中文，仅转换字形，内容与标点未改动。译文为忠实完整的讲述：按原文顺序逐段讲述，不增人物，不改结局，不作梗概；段内句子连续，不逐句分行。

底本说明：维基文库卷二页面原文中，本篇为单一段落，末句为“彼限我十天往复，故可暂依耳。”，该页摘录中未见异史氏曰一段，故正文与译文均不含异史氏曰。译文为便于配图，按情节自然断为 3 段，顺序与内容与原文一致：相识亲密、升迁报丧与河边送别、谒河神后送渡。

## 人物表

- 朱公：汾州通判，住在官署；夜坐时遇见狐女，后升迁报至又因母丧解任，欲与狐女同归。
- 狐女：容光艳丽的狐狸所化女子；先与朱公亲密往来，后预言升迁与丧事，初称狐不能过河，后谒河神得十天往返之限，送朱公渡河。
- 河神：狐女所谒的故旧，准许狐女十天之内往返。
- 太夫人：朱公之母，讣告所指之人，未出场。
