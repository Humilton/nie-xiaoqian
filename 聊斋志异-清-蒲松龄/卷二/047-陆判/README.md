# 047 陆判

## 翻译说明（只写在这里，不写进正文）

这篇故事出自清代蒲松龄的《聊斋志异》卷二，篇名《陆判》，以下讲述是 Muse 的翻译，只把文言换成今天的话来讲，原意、人物、情节顺序和结局都不改，没有增加人物，没有改动结局，换心、换头的情节按原文保留，描写收着写，不血腥、不渲染。

## 底本

维基文库公有领域原文《聊斋志异/第02卷》中的《陆判》一节，已按简体字转写，内容与段落划分不变；未抄现代整理本校注，未抄现代译文。原文第 5 段在维基文库页面上跨行断开（“陆”与“判官”分属两行），转写时已按原文接回一段。

## 人物表

- 朱尔旦：陵阳书生，字小明，青年，性情豪放而向来迟钝；深青色长衫，黑色发髻。换心后文思大进，中经魁；晚年为鬼，任太华卿。
- 陆判官：十王殿东廊判官，绿面赤须，黑色判官袍，黑色判官帽；木雕神像出身，后为朱尔旦的鬼友，为他换心、为其妻换头。
- 朱妻：朱尔旦的结发妻子，换头前头面不佳，换头后为长眉掩鬓、笑靥承颧的美人面貌，颈有一圈红线。
- 吴侍御之女：美貌，未嫁而丧二夫，十九岁未嫁，上元游十王殿时被苏溪杨大年所害；其头被陆判官取与朱妻相换，死后托梦自言真相。
- 杨大年：苏溪人，杀害吴女的贼子，后被执拿伏罪。
- 朱玮：朱尔旦之子，五岁丧父（不知无父），十五入邑庠，二十五举进士，官行人，华阴道上与父相见，后官至司马；佩刀后赠其子浑，浑仕为总宪。
