## 人物表（本篇形象统一）

- 傅廉：十七岁少年书生，黑色发髻，素色淡蓝灰长袍。
- 巧娘：十七八岁女郎，长发，淡粉白汉服；鬼，才貌无双，嫁毛家小郎子后守寡。
- 三娘：与巧娘同龄的狐女，浅绿汉服；华姑之女。
- 华姑：约五十余岁妇人，深紫袍、简发髻，风韵犹存；三娘之母。
- 傅父、傅母：广东缙绅夫妇。
- 毛家小郎子：巧娘前夫，有阉疾，十八岁而不能人事，含恨而死（仅提及，未出场）。
- 吴郎：三姐家信中已死的丈夫（仅提及）。
