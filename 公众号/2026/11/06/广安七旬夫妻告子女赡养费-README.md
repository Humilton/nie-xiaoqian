## 已核实事实（均可追溯到来源）

- 王某某、夏某某夫妇均已七十有余，一共育有五个子女。
- 2001年，全家签订分家协议，约定四个儿子每人每月给付赡养费20元，合计每月80元。
- 二老常年受慢性病困扰，日常用药、就医开销不断增加；物价持续上涨，当年定下的标准早已不足以支撑基本生活。
- 五名子女虽具备赡养能力，但对赡养费标准始终无法达成一致；协商未果，二老诉至法院。
- 承办法官认为：分家协议出自一家人真实意愿，应当予以尊重，但赡养义务并非一成不变；赡养费标准应当结合老人实际需求、健康状况、当地生活水平以及子女经济条件动态调整，不能固守多年前的旧约定。
- 老年人权益保障法第二十条：经老年人同意，赡养人之间可以就履行赡养义务签订协议，赡养协议的内容不得违反法律的规定和老年人的意愿。
- 广安市中级人民法院判决：五名子女自2025年起，每人每年向两位老人合计支付赡养费七千余元，五名子女一年合计支付约3.5万元。
- 法官提醒：民法典第一千零六十七条（成年子女不履行赡养义务，缺乏劳动能力或者生活困难的父母有权要求成年子女给付赡养费）；老年人权益保障法第十四条（赡养人应当履行经济上供养、生活上照料和精神上慰藉的义务）；第十九条（赡养人不得以放弃继承权或者其他理由拒绝履行赡养义务）；随着老人身体机能衰退、医疗开支增加，赡养成本相应增加，子女不能以早年约定为由拒绝根据现实情况提高费用。
