## 已核实事实

- 李某与孙某登记结婚时，孙某与前妻的孩子孙某1（6岁）、孙某2（3岁）均未成年。
- 李某作为继母，婚后对二人履行了抚养、教育义务，直至成年。
- 现李某年迈患病，没有固定住所；孙某1、孙某2不尽赡养义务，李某起诉请求支付赡养费。
- 法院依据《中华人民共和国民法典》第一千零七十二条第二款，认定继子女受继父母抚养教育形成拟制血亲关系，权利义务适用父母子女关系的规定，判决孙某1、孙某2向李某按月支付赡养费。
- 典型意义原文：生恩重，养恩亦重；符合“你养我小、我养你老”的社会朴素认知。
